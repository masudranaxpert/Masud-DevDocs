## Subquery মানে কী?

Subquery মানে হলো — **একটা query-এর ভেতরে আরেকটা query।**

একে বলা হয় **Inner Query** বা **Nested Query।** আর যেটার ভেতরে থাকে সেটা হলো **Outer Query।**

```sql
SELECT *
FROM job_postings_fact
WHERE salary > (SELECT AVG(salary) FROM job_postings_fact)
--              ↑ এটাই Subquery / Inner Query
```

<Callout type="info" title="কোনটা আগে চলে?">
  সবসময় **Inner query আগে execute হয়,** তারপর তার result Outer query-তে পাঠানো হয়।
</Callout>

### তিনটা জায়গায় কীভাবে লেখে?

<Tabs items={['WHERE', 'FROM', 'SELECT']}>
  <Tab value="WHERE">
    ```sql
    -- Average salary-এর চেয়ে বেশি যারা
    SELECT job_title, salary_year_avg
    FROM job_postings_fact
    WHERE salary_year_avg > (SELECT AVG(salary_year_avg) FROM job_postings_fact)
    ```
    এখানে inner query একটাই number দেয় (AVG), তারপর `>` দিয়ে compare করা হয়।
  </Tab>
  <Tab value="FROM">
    ```sql
    -- প্রতিটা job title-এর average salary বের করো, তারপর filter করো
    SELECT *
    FROM (
        SELECT job_title_short, AVG(salary_year_avg) AS avg_salary
        FROM job_postings_fact
        GROUP BY job_title_short
    ) AS title_avg
    WHERE avg_salary > 100000
    ```
    <Callout type="warn" title="Alias দিতেই হবে!">
      FROM-এ subquery লিখলে অবশ্যই একটা **alias** দিতে হবে। উপরে `title_avg` দেওয়া আছে — না দিলে error।
    </Callout>
  </Tab>
  <Tab value="SELECT">
    ```sql
    -- প্রতিটা job-এর salary এবং overall average একসাথে দেখাও
    SELECT
        job_title,
        salary_year_avg,
        (SELECT AVG(salary_year_avg) FROM job_postings_fact) AS overall_avg
    FROM job_postings_fact
    ```
    প্রতিটা row-এর পাশে একটা fixed value (overall average) দেখাবে।
  </Tab>
</Tabs>

## Subquery কতটা Return করতে পারে?

| Return Type | মানে | কোথায় ব্যবহার |
|---|---|---|
| **Single value** (scalar) | একটাই number/text | `=`, `>`, `<` এর সাথে |
| **Single column** | অনেক row, একটা column | `IN`, `ANY`, `ALL` এর সাথে |
| **Full table** | অনেক row, অনেক column | `FROM` clause-এ |

```sql
-- Single value
WHERE salary > (SELECT AVG(salary) FROM job_postings_fact)

-- Single column — IN এর সাথে
WHERE job_id IN (SELECT job_id FROM job_postings_fact WHERE job_country = 'US')

-- Full table — FROM এ
FROM (SELECT * FROM job_postings_fact WHERE salary_year_avg > 50000) AS high_pay
```

## Real Example — Window Function + Subquery

আগের lesson-এ `ROW_NUMBER()` শিখেছিলাম। সেটা filter করতে হলে **Subquery লাগবেই।**

<Steps>
  <Step>
    ### Inner query-তে ROW_NUMBER() দিয়ে rank করো
    ```sql
    SELECT
        job_title_short,
        job_location,
        salary_year_avg,
        ROW_NUMBER() OVER (
            PARTITION BY job_title_short
            ORDER BY salary_year_avg DESC
        ) AS rn
    FROM job_postings_fact
    ```
  </Step>
  <Step>
    ### Outer query-তে filter করো
    ```sql
    SELECT *
    FROM (
        SELECT
            job_title_short,
            job_location,
            salary_year_avg,
            ROW_NUMBER() OVER (
                PARTITION BY job_title_short
                ORDER BY salary_year_avg DESC
            ) AS rn
        FROM job_postings_fact
    ) AS ranked
    WHERE rn <= 3
    ```
  </Step>
</Steps>

<Callout type="idea" title="কেন সরাসরি WHERE দিয়ে filter করা যায় না?">
  `WHERE` clause execute হয় `ROW_NUMBER()` এর **আগে।** তাই `rn` column টা তখনও তৈরি হয়নি। Subquery দিয়ে আগে `rn` বানাও, তারপর বাইরে filter করো।
</Callout>

## Subquery vs JOIN

<Tabs items={['Subquery দিয়ে', 'JOIN দিয়ে']}>
  <Tab value="Subquery দিয়ে">
    ```sql
    SELECT job_title
    FROM job_postings_fact
    WHERE company_id IN (
        SELECT company_id
        FROM company_dim
        WHERE country = 'US'
    )
    ```
    পড়তে সহজ, step-by-step বোঝা যায়।
  </Tab>
  <Tab value="JOIN দিয়ে">
    ```sql
    SELECT j.job_title
    FROM job_postings_fact j
    JOIN company_dim c ON j.company_id = c.company_id
    WHERE c.country = 'US'
    ```
    অনেক column দরকার হলে বা performance গুরুত্বপূর্ণ হলে JOIN ভালো।
  </Tab>
</Tabs>

## Quick Summary

<Callout title="মনে রাখো">
- Subquery সবসময় `()` parentheses-এর ভেতরে লিখতে হবে
- Inner query **আগে** চলে, Outer query **পরে**
- `FROM`-এ subquery লিখলে **alias** দিতেই হবে
- Window function filter করতে হলে **Subquery ছাড়া উপায় নেই**
</Callout>
