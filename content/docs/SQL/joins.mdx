## JOIN কেন দরকার?

Real database এ data সাধারণত অনেক table এ ভাগ করা থাকে। JOIN দিয়ে একাধিক table এক query তে একসাথে আনা যায়।

```
employees table:          departments table:
id | name | dept_id      id | dept_name
1  | Rahim | 2           1  | HR
2  | Karim | 1           2  | Engineering
3  | Sadia | 2           3  | Finance
```

## INNER JOIN

দুই table এ **match করে** এমন rows শুধু দেখাবে।

### Syntax

```sql
SELECT কোন_কোন_column
FROM প্রথম_table
INNER JOIN দ্বিতীয়_table
ON প্রথম_table.column = দ্বিতীয়_table.column;
```

### উদাহরণ

```sql
SELECT employees.name, departments.dept_name
FROM employees
INNER JOIN departments
ON employees.dept_id = departments.id;
```

**Result:**

| name | dept_name |
|---|---|
| Rahim | Engineering |
| Karim | HR |
| Sadia | Engineering |

<Callout type="info" title="Foreign Key হতেই হবে না">
  `ON` এর মধ্যে যেকোনো দুইটা column equal হলেই হয় — Foreign Key/Primary Key বাধ্যতামূলক না। শুধু value match করলেই JOIN কাজ করবে।
</Callout>

## Alias দিয়ে সংক্ষিপ্ত করো

Table এর নাম alias দিলে query ছোট হয়:

```sql
-- e = employees, d = departments
SELECT e.name, e.salary, d.dept_name
FROM employees e
INNER JOIN departments d ON e.dept_id = d.id
WHERE d.dept_name = 'Engineering'
ORDER BY e.salary DESC;
```

## LEFT JOIN

বাম table (FROM) এর **সব rows** দেখাবে। ডান table এ match না থাকলে `NULL` আসবে।

```sql
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id;
```

| name | dept_name |
|---|---|
| Rahim | Engineering |
| Karim | HR |
| Nadia | NULL ← কোনো department নেই |

<Callout type="info" title="কখন LEFT JOIN?">
  "সব employees দেখাও, department থাকুক বা না থাকুক" — এই ধরনের প্রশ্নে LEFT JOIN।
</Callout>

## Multiple JOIN

একসাথে তিনটা table JOIN করা যায়:

```sql
SELECT
    e.name,
    d.dept_name,
    p.project_name
FROM employees e
INNER JOIN departments d ON e.dept_id = d.id
INNER JOIN projects p ON e.project_id = p.id
WHERE d.dept_name = 'Engineering';
```

## JOIN এর সাথে GROUP BY

```sql
-- প্রতিটা department এ কতজন কর্মী এবং average salary
SELECT
    d.dept_name,
    COUNT(e.id) AS total_employees,
    AVG(e.salary) AS avg_salary
FROM departments d
LEFT JOIN employees e ON d.id = e.dept_id
GROUP BY d.dept_name
ORDER BY avg_salary DESC;
```

## Self JOIN — একই table নিজের সাথে

```sql
-- Manager এর নাম বের করো (manager ও employee table এর মধ্যেই আছে)
SELECT
    e.name AS employee,
    m.name AS manager
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.id;
```
