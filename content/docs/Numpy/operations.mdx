## Element-wise Arithmetic

```python
import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

# Basic ops — সব element-wise
a + b       # → [11 22 33 44]
a - b       # → [-9 -18 -27 -36]
a * b       # → [10 40 90 160]
b / a       # → [10. 10. 10. 10.]
b // a      # → [10 10 10 10]  (integer division)
a ** 2      # → [1 4 9 16]     (power)
b % a       # → [0 0 0 0]      (modulo)

# Scalar operation — broadcasting
a + 10      # → [11 12 13 14]
a * 2       # → [2 4 6 8]
a / 2       # → [0.5 1. 1.5 2.]

# In-place — নতুন array তৈরি না করে
a += 1      # a ই পরিবর্তন হয়
a *= 2
```

## Axis বোঝো — সবচেয়ে confusing

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])
# shape: (2, 3)
# axis=0 → rows এর দিকে (down ↓)
# axis=1 → columns এর দিকে (across →)

np.sum(m)           # → 21        (সব elements)
np.sum(m, axis=0)   # → [5 7 9]   (column-wise sum ↓)
np.sum(m, axis=1)   # → [6 15]    (row-wise sum →)

np.mean(m, axis=0)  # → [2.5 3.5 4.5]  (column mean)
np.mean(m, axis=1)  # → [2. 5.]        (row mean)

np.max(m, axis=0)   # → [4 5 6]   (column max)
np.max(m, axis=1)   # → [3 6]     (row max)
```

**মনে রাখার trick:**
- `axis=0` মানে **সেই axis কে collapse করো** — rows কমে যায়, columns থাকে → column-wise result
- `axis=1` মানে **columns collapse** → row-wise result
- `axis=-1` মানে **last axis** (যেকোনো dimension এর জন্য safe)

## Reduction Operations

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

# Sum / Product
np.sum(a)              # → 21
np.sum(a, axis=0)      # → [5 7 9]
np.prod(a)             # → 720
np.cumsum(a)           # → [ 1  3  6 10 15 21]  (cumulative, flattened)
np.cumsum(a, axis=1)   # → [[1 3 6] [4 9 15]]

# Min / Max
np.min(a)              # → 1
np.max(a, axis=1)      # → [3, 6]
np.argmin(a)           # → 0  (flat index)
np.argmax(a, axis=0)   # → [1 1 1]  (row index of max per column)

# Statistics
np.mean(a)             # → 3.5
np.median(a)           # → 3.5
np.std(a)              # → standard deviation
np.var(a)              # → variance

# Conditional sum/mean (NaN-safe)
np.nansum(a)           # → NaN values ignore করে sum
np.nanmean(a)          # → NaN ignore করে mean
```

## np.where — Conditional Operation

```python
arr = np.array([1, -2, 3, -4, 5, -6])

# np.where(condition, true_value, false_value)
result = np.where(arr > 0, arr, 0)
# → [1 0 3 0 5 0]  (negative গুলো 0 হয়ে গেছে)

result = np.where(arr > 0, arr, -arr)
# → [1 2 3 4 5 6]  (absolute value)

# 2D array তে
m = np.array([[1, 2, 3], [4, 5, 6]])
np.where(m % 2 == 0, m * 10, m)
# → [[ 1 20  3]
#    [40  5 60]]

# Just condition — True elements এর indices
np.where(arr > 0)
# → (array([0, 2, 4]),)  (tuple of index arrays)

# np.select — multiple conditions
conditions = [arr < 0, arr == 0, arr > 0]
choices    = [-1,      0,        1]
np.select(conditions, choices)
# → [-1 -1 1 -1 1 -1]  (sign function)
```

## Vectorization — Loop এড়াও

```python
# ❌ ভুল — Python loop, slow
data = np.random.randn(1_000_000)
result = np.zeros(len(data))
for i in range(len(data)):
    if data[i] > 0:
        result[i] = data[i] ** 2
    else:
        result[i] = data[i] ** 3

# ✅ সঠিক — vectorized, 50-100x faster
result = np.where(data > 0, data ** 2, data ** 3)

# ❌ string processing loop
words = np.array(['hello', 'world', 'numpy'])
lengths = []
for w in words:
    lengths.append(len(w))

# ✅ vectorized (NumPy 2.0+ strings namespace)
lengths = np.strings.str_len(words)
# অথবা
lengths = np.array([len(w) for w in words])  # এটাও ঠিক
```

## Dot Product ও Matrix Multiplication

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# 1D dot product (inner product)
np.dot(a, b)       # → 32  (1*4 + 2*5 + 3*6)
a @ b              # → 32  (@ operator, Python 3.5+)

# 2D matrix multiplication
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

np.dot(A, B)       # → [[19 22] [43 50]]
A @ B              # → same
A * B              # → element-wise! [[5 12] [21 32]]  ← different!

# np.matmul vs np.dot — 3D এ behavior আলাদা
# np.matmul → batch matrix multiply
# np.dot → sum product over last axis
```

<Callout type="warn" title="@ vs * — সবচেয়ে common ভুল">
  `A * B` → element-wise multiply। `A @ B` → matrix multiply।
  Neural network, linear algebra তে সবসময় `@` বা `np.matmul` ব্যবহার করো।
</Callout>
