## ndarray কী?

NumPy এর মূল হলো `ndarray` — N-dimensional array। এটা একটা **fixed-size, same-type** এর elements এর grid।

```python
import numpy as np

a = np.array([1, 2, 3, 4, 5])

print(a.ndim)   # → 1       (dimensions সংখ্যা)
print(a.shape)  # → (5,)    (প্রতিটা dimension এর size)
print(a.size)   # → 5       (মোট elements)
print(a.dtype)  # → int64   (element type)
print(a.nbytes) # → 40      (মোট memory bytes)
print(a.itemsize) # → 8     (একটা element এর bytes)
```

## dtype — Data Types

```python
# Integer types
np.int8     # -128 to 127
np.int16    # -32,768 to 32,767
np.int32    # ~ -2 billion to 2 billion
np.int64    # default int (64-bit)

np.uint8    # 0 to 255 (unsigned — image data)
np.uint16   # 0 to 65,535
np.uint32
np.uint64

# Float types
np.float16  # 16-bit (machine learning — less memory)
np.float32  # 32-bit (GPU computation, ML)
np.float64  # default float (64-bit, double precision)

# Other
np.bool_    # True/False
np.complex64
np.complex128
np.str_     # fixed-length string (পুরনো)
# NumPy 2.0+:
np.dtypes.StringDType()  # variable-length string (নতুন!)

# Check করো
arr = np.array([1, 2, 3])
arr.dtype        # → dtype('int64')
arr.dtype.name   # → 'int64'
arr.dtype.itemsize # → 8
```

### dtype কেন গুরুত্বপূর্ণ

```python
# ❌ ভুল — default int64 দিলে memory বেশি লাগে
images = np.zeros((1000, 224, 224, 3))          # float64 = 1.2 GB!

# ✅ সঠিক — image data এ float32 বা uint8
images = np.zeros((1000, 224, 224, 3), dtype=np.float32)   # 600 MB
images = np.zeros((1000, 224, 224, 3), dtype=np.uint8)     # 150 MB

# dtype convert করো
arr = np.array([1, 2, 3])
arr.astype(np.float32)      # float32 এ convert
arr.astype(np.float64)      # float64
arr.astype(bool)            # boolean — 0→False, else True
```

## Array Attributes

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

a.ndim    # → 2          (মাত্রা সংখ্যা)
a.shape   # → (2, 3)     (rows, cols)
a.size    # → 6          (মোট elements)
a.dtype   # → int64      (data type)
a.nbytes  # → 48         (total bytes = 6 * 8)
a.T       # → transposed (3, 2) — same data, different view
a.flat    # → 1D iterator
a.real    # → real part (complex array এ)
a.imag    # → imaginary part
```

## Array তৈরির সময় সব ভুল

<Callout title="Beginners এর সব ভুল">

```python
# ❌ ভুল 1 — mixed types, unexpected dtype
arr = np.array([1, 2, 3.0])    # → float64! (int + float → float)
arr = np.array([1, 2, True])   # → int64!  (bool + int → int)
arr = np.array([1, 'two', 3])  # → '<U21'  (string!)

# ✅ সবসময় dtype specify করো important array এ
arr = np.array([1, 2, 3], dtype=np.float32)

# ❌ ভুল 2 — list of lists uneven rows
arr = np.array([[1, 2, 3], [4, 5]])  # → object dtype, not 2D!

# ✅ সব rows same length হতে হবে
arr = np.array([[1, 2, 3], [4, 5, 6]])  # ✅ proper 2D

# ❌ ভুল 3 — NumPy 2.x এ removed হয়েছে
a = np.array([1.5])
scalar = np.float64(a)   # → TypeError in NumPy 2.0!

# ✅ সঠিক scalar extract করো
scalar = a.item()     # Python scalar
scalar = a[0]         # NumPy scalar
scalar = float(a[0])  # Python float
```
</Callout>
