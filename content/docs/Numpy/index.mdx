## NumPy কী?

NumPy হলো Python এর সবচেয়ে important scientific computing library। Pandas, Scikit-learn, TensorFlow, PyTorch — সব NumPy এর উপরে build করা।

**কেন NumPy?**
- Python list এর চেয়ে **10–100x দ্রুত** — C তে লেখা, SIMD optimized
- **Vectorization** — loop ছাড়াই array operation
- **Broadcasting** — different shape এ operation
- **Memory efficient** — contiguous memory block

### NumPy 2.0+ এ Remove হয়েছে যা জানতে হবে

```python
# ❌ আগের code (NumPy 1.x)
arr.reshape(newshape=(3, 4))           # newshape parameter removed
np.core.umath_tests                    # np.core removed
result = np.float32(arr)               # ndim>0 array → scalar (removed)

# ✅ NumPy 2.x সঠিক
arr.reshape((3, 4))                    # positional অথবা shape=
arr.reshape(shape=(3, 4))             # shape= keyword
arr.item()                             # scalar extract করো
arr[0]                                 # single element
```

## NumPy vs Python List

```python
import numpy as np
import time

n = 10_000_000

# Python list
lst = list(range(n))
start = time.perf_counter()
result = [x * 2 for x in lst]
print(f"List:  {time.perf_counter() - start:.3f}s")

# NumPy array
arr = np.arange(n)
start = time.perf_counter()
result = arr * 2
print(f"NumPy: {time.perf_counter() - start:.3f}s")

# NumPy: ~10-50x faster!
```
