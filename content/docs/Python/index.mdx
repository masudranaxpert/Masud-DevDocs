## Python 3.13 + 3.14 — গুরুত্বপূর্ণ নতুন features

```python
# 1. t-strings (Python 3.14) — PEP 750
name = "Rahim"
user_input = "<script>alert('xss')</script>"

# f-string → str হয়ে যায়, dangerous হতে পারে
f"Hello, {user_input}"   # XSS risk!

# t-string → Template object, safe processing করা যায়
tmpl = t"Hello, {user_input}"   # Template, not str
# type(tmpl) → string.templatelib.Template

# 2. match/case (Python 3.10+) — Pattern matching
match command.split():
    case ["go", direction]:
        print(f"Going {direction}")
    case ["quit"]:
        exit()

# 3. Type hints উন্নতি (Python 3.10+)
def process(x: int | float) -> str:    # Union → | syntax
    return str(x)

# 4. Exception Groups (Python 3.11+)
try:
    raise ExceptionGroup("errors", [
        ValueError("bad value"),
        TypeError("bad type"),
    ])
except* ValueError as eg:
    print(f"ValueError: {eg}")

# 5. try/finally control flow warning (Python 3.14)
# finally block এ return/break/continue → DeprecationWarning now
```

## Install ও Setup

```bash
# Install
# Windows/Mac: python.org থেকে 3.14 installer
# Linux:
sudo apt install python3.14
# অথবা pyenv দিয়ে (recommended)
pyenv install 3.14.0
pyenv global 3.14.0

# Version check
python --version    # Python 3.14.x

# Virtual environment (সবসময় use করো!)
python -m venv .venv
source .venv/bin/activate     # Linux/Mac
.venv\Scripts\activate        # Windows

# Package manager
pip install package_name
# অথবা uv (faster, recommended in 2025)
uv pip install package_name
```
