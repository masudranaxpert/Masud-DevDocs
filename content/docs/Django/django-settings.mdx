## Settings Structure

```
config/settings/
├── __init__.py
├── base.py          ← সব জায়গায় common
├── development.py   ← শুধু local dev
└── production.py    ← শুধু server
```

## development.py

```python
from .base import *

DEBUG = True
ALLOWED_HOSTS = ['localhost', '127.0.0.1']

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': env('DB_NAME'),
        'USER': env('DB_USER'),
        'PASSWORD': env('DB_PASSWORD'),
        'HOST': env('DB_HOST', default='localhost'),
        'PORT': env('DB_PORT', default='5432'),
    }
}

# Dev এ সব SQL query দেখো
LOGGING = {
    'version': 1,
    'handlers': {'console': {'class': 'logging.StreamHandler'}},
    'loggers': {
        'django.db.backends': {'level': 'DEBUG', 'handlers': ['console']},
    },
}

# Dev এ email console এ print হবে
EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'
```

## production.py

```python
from .base import *

DEBUG = False
ALLOWED_HOSTS = env.list('ALLOWED_HOSTS')

# HTTPS
SECURE_SSL_REDIRECT             = True
SECURE_HSTS_SECONDS             = 31536000
SECURE_HSTS_INCLUDE_SUBDOMAINS  = True
SECURE_HSTS_PRELOAD             = True
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')

SESSION_COOKIE_SECURE = True
CSRF_COOKIE_SECURE    = True
SESSION_COOKIE_HTTPONLY = True

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': env('DB_NAME'),
        'USER': env('DB_USER'),
        'PASSWORD': env('DB_PASSWORD'),
        'HOST': env('DB_HOST'),
        'PORT': env('DB_PORT', default='5432'),
        'CONN_MAX_AGE': 60,   # connection pooling
    }
}

STATIC_ROOT = BASE_DIR / 'staticfiles'

# Cache
CACHES = {
    'default': {
        'BACKEND': 'django.core.cache.backends.redis.RedisCache',
        'LOCATION': env('REDIS_URL', default='redis://localhost:6379/1'),
    }
}

# Email
EMAIL_BACKEND  = 'django.core.mail.backends.smtp.EmailBackend'
EMAIL_HOST     = env('EMAIL_HOST')
EMAIL_PORT     = env.int('EMAIL_PORT', default=587)
EMAIL_USE_TLS  = True
EMAIL_HOST_USER     = env('EMAIL_HOST_USER')
EMAIL_HOST_PASSWORD = env('EMAIL_HOST_PASSWORD')

# Django 6 CSP
from django.utils.csp import CSP
SECURE_CSP = {
    'default-src': [CSP.SELF],
    'script-src': [CSP.SELF, CSP.NONCE],
    'img-src': [CSP.SELF, 'https:', 'data:'],
}
MIDDLEWARE = ['django.middleware.csp.ContentSecurityPolicyMiddleware'] + MIDDLEWARE
```

## .env Template

`.env` (local only — git ignore):
```
SECRET_KEY=50+characters-random-string-here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
DB_NAME=mydb
DB_USER=myuser
DB_PASSWORD=mypassword
DB_HOST=localhost
DB_PORT=5432
REDIS_URL=redis://localhost:6379/1
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_HOST_USER=myapp@gmail.com
EMAIL_HOST_PASSWORD=app-specific-password
```

`.env.example` (git এ commit করো):
```
SECRET_KEY=
DEBUG=True
ALLOWED_HOSTS=
DB_NAME=
DB_USER=
DB_PASSWORD=
DB_HOST=localhost
DB_PORT=5432
```

<Callout type="warn" title="কখনো .env git এ push করো না">
  `.gitignore` এ `.env` অবশ্যই থাকবে। `.env.example` দিয়ে team কে guide করো।
</Callout>
