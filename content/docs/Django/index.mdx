## Django Request/Response Cycle

```
Browser → Nginx/Caddy (reverse proxy)
               ↓
         Gunicorn/Uvicorn (WSGI/ASGI)
               ↓
         Django Middleware Stack (top → bottom)
               ↓
         URL Dispatcher → View
               ↓
         Model / ORM → Database
               ↓
         Template Rendering
               ↓
         Middleware Stack (bottom → top)
               ↓
         Browser
```
