## Basic Commands

```bash
# Migration file তৈরি করো
python manage.py makemigrations
python manage.py makemigrations products   # specific app

# Database এ apply করো
python manage.py migrate
python manage.py migrate products          # specific app
python manage.py migrate products 0003    # specific version পর্যন্ত

# SQL দেখো (apply করার আগে review করো)
python manage.py sqlmigrate products 0001_initial

# Status দেখো
python manage.py showmigrations
python manage.py showmigrations products

# CI/CD এ unapplied আছে কিনা check
python manage.py migrate --check
```

## Workflow

```
model.py change করো
        ↓
python manage.py makemigrations   ← migration file তৈরি
        ↓
migration file review করো         ← important! SQL দেখো
        ↓
python manage.py migrate           ← database apply
        ↓
git add && git commit               ← migration file commit করো
```

## Data Migration — RunPython

Schema change ছাড়া শুধু data manipulate করতে।

```python
from django.db import migrations
from django.utils.text import slugify

def populate_slugs(apps, schema_editor):
    # ✅ apps.get_model() ব্যবহার করো — direct import না
    Product = apps.get_model('products', 'Product')
    for product in Product.objects.filter(slug=''):
        product.slug = slugify(product.name)
        product.save(update_fields=['slug'])

def reverse_slugs(apps, schema_editor):
    Product = apps.get_model('products', 'Product')
    Product.objects.update(slug='')

class Migration(migrations.Migration):
    dependencies = [
        ('products', '0005_add_slug_field'),
    ]
    operations = [
        migrations.RunPython(populate_slugs, reverse_code=reverse_slugs),
    ]
```

<Callout type="warn" title="apps.get_model() ব্যবহার করো">
  `from apps.products.models import Product` — এভাবে import করলে ভবিষ্যতে model change হলে পুরনো migrations ভেঙে যাবে।
  সবসময় `apps.get_model('app_label', 'ModelName')` ব্যবহার করো।
</Callout>

## Rollback করো

```bash
# Previous migration এ ফিরে যাও
python manage.py migrate products 0003   # 0003 এ থাকবে
python manage.py migrate products zero   # সব rollback

# Fake — already applied কিন্তু record নেই
python manage.py migrate --fake products 0001
```

## squashmigrations — পুরনো অনেক migration clean করো

```bash
# 0001 থেকে 0020 কে একটায় merge করো
python manage.py squashmigrations products 0001 0020
```

## Large Table Migration

```python
# ❌ বিপজ্জনক — large table এ non-nullable column add
migrations.AddField(
    model_name='product',
    name='new_field',
    field=models.CharField(max_length=100),  # default ছাড়া! table lock হবে
)

# ✅ Safe — nullable করে add, পরে constraint যোগ করো
migrations.AddField(
    model_name='product',
    name='new_field',
    field=models.CharField(max_length=100, null=True, blank=True),
)
```
