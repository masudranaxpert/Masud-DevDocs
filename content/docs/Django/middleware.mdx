## Built-in Middleware

```python
# settings.py
MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',         # HTTPS redirect, headers
    'django.contrib.sessions.middleware.SessionMiddleware',  # Session support
    'django.middleware.common.CommonMiddleware',             # URL normalization
    'django.middleware.csrf.CsrfViewMiddleware',            # CSRF protection
    'django.contrib.auth.middleware.AuthenticationMiddleware', # request.user
    'django.contrib.messages.middleware.MessageMiddleware',  # messages framework
    'django.middleware.clickjacking.XFrameOptionsMiddleware', # X-Frame-Options
    # Django 6:
    'django.middleware.csp.ContentSecurityPolicyMiddleware', # CSP header
]
```

<Callout type="warn" title="Middleware Order গুরুত্বপূর্ণ">
  `SessionMiddleware` অবশ্যই `AuthenticationMiddleware` এর আগে।
  `SecurityMiddleware` সবার প্রথমে (HTTPS redirect এর জন্য)।
  Custom middleware যোগ করলে order ভেবে দাও।
</Callout>

## Custom Middleware — Function Style

```python
# apps/core/middleware.py
import time
import logging

logger = logging.getLogger(__name__)

def request_timing_middleware(get_response):
    """প্রতিটা request কতক্ষণ লাগলো log করো"""
    def middleware(request):
        start = time.perf_counter()
        response = get_response(request)
        duration = time.perf_counter() - start

        if duration > 1.0:
            logger.warning(f'Slow: {request.method} {request.path} — {duration:.2f}s')

        response['X-Response-Time'] = f'{duration:.3f}s'
        return response

    return middleware
```

## Custom Middleware — Class Style

```python
class MaintenanceModeMiddleware:
    """Maintenance mode এ সব request block করো"""
    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        from django.conf import settings
        from django.http import HttpResponse

        if getattr(settings, 'MAINTENANCE_MODE', False):
            # Admin ও staff কে allow করো
            if not request.path.startswith('/admin/') and not (
                request.user.is_authenticated and request.user.is_staff
            ):
                return HttpResponse(
                    'Site is under maintenance. Please try later.',
                    status=503
                )

        return self.get_response(request)


class CurrentUserMiddleware:
    """Thread-local storage এ current user রাখো — Service layer তে use করতে"""
    _user = None

    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        CurrentUserMiddleware._user = request.user if request.user.is_authenticated else None
        response = self.get_response(request)
        CurrentUserMiddleware._user = None
        return response

    @classmethod
    def get_current_user(cls):
        return cls._user
```

## Process Exception — Error Handle করো

```python
class GlobalExceptionMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        return self.get_response(request)

    def process_exception(self, request, exception):
        """Unhandled exception হলে log করো"""
        import logging
        logger = logging.getLogger(__name__)
        logger.error(
            f'Unhandled exception: {exception}',
            exc_info=True,
            extra={'request': request}
        )
        # None return করলে Django default error handling চলবে
        return None
```

## Middleware Use Cases

| Middleware | কাজ |
|---|---|
| Request timing | Slow request detect করো |
| IP blocking | Banned IP থেকে request block করো |
| Maintenance mode | Site down করো selectively |
| API rate limiting | Request per minute limit করো |
| Request logging | Audit log রাখো |
| Tenant detection | Multi-tenant app এ tenant detect করো |
