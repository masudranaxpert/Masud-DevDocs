## Common Vulnerabilities

<Tabs items={['XSS', 'CSRF', 'SQL Injection', 'File Upload']}>
  <Tab value="XSS">
    ```html
    <!-- ❌ XSS vulnerable -->
    {{ user_comment|safe }}   {# user script inject করতে পারবে! #}

    <!-- ✅ Django auto-escape — এটাই default, নিরাপদ -->
    {{ user_comment }}
    <!-- < → &lt;, > → &gt;, " → &quot; -->

    <!-- Trusted HTML দেখাতে হলে sanitize করো আগে -->
    ```
    ```python
    # pip install bleach
    import bleach
    from django.utils.safestring import mark_safe

    safe_html = mark_safe(bleach.clean(
        user_html,
        tags=['p', 'b', 'i', 'u', 'a'],
        attributes={'a': ['href']},
    ))
    ```
  </Tab>
  <Tab value="CSRF">
    ```html
    <!-- সব POST form এ দাও -->
    <form method="post">
        {% csrf_token %}
        ...
    </form>
    ```
    ```javascript
    // AJAX POST এ
    const csrfToken = document.querySelector('[name=csrfmiddlewaretoken]').value;
    fetch('/api/endpoint/', {
        method: 'POST',
        headers: {
            'X-CSRFToken': csrfToken,
            'Content-Type': 'application/json',
        },
        body: JSON.stringify(data),
    });
    ```
  </Tab>
  <Tab value="SQL Injection">
    ```python
    # ❌ SQL Injection!
    name = request.GET.get('name')
    Product.objects.raw(f"SELECT * FROM products WHERE name = '{name}'")
    # name = "'; DROP TABLE products; --" হলে সর্বনাশ!

    # ✅ ORM — automatically parameterized
    Product.objects.filter(name=name)

    # Raw SQL লাগলে parameterized ব্যবহার করো
    Product.objects.raw(
        "SELECT * FROM products WHERE name = %s",
        [name]   # ← parameter হিসেবে পাঠাও
    )
    ```
  </Tab>
  <Tab value="File Upload">
    ```python
    import os
    from django.core.exceptions import ValidationError

    def validate_file(value):
        ext = os.path.splitext(value.name)[1].lower()
        if ext not in ['.jpg', '.jpeg', '.png', '.pdf']:
            raise ValidationError('Invalid file type.')
        if value.size > 5 * 1024 * 1024:   # 5MB limit
            raise ValidationError('File too large.')

    class Document(models.Model):
        file = models.FileField(
            upload_to='documents/',
            validators=[validate_file]
        )
    ```
  </Tab>

## Production Security Settings

```python
# settings/production.py
DEBUG = False   # ← সবচেয়ে গুরুত্বপূর্ণ!

SECURE_SSL_REDIRECT            = True
SECURE_HSTS_SECONDS            = 31536000
SECURE_HSTS_INCLUDE_SUBDOMAINS = True
SECURE_HSTS_PRELOAD            = True
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')

SESSION_COOKIE_SECURE  = True   # HTTPS only cookie
CSRF_COOKIE_SECURE     = True   # HTTPS only
SESSION_COOKIE_HTTPONLY = True  # JS access করতে পারবে না
X_FRAME_OPTIONS        = 'DENY' # clickjacking prevent

# Django 6 — CSP
from django.utils.csp import CSP
SECURE_CSP = {
    'default-src': [CSP.SELF],
    'script-src': [CSP.SELF, CSP.NONCE],
    'img-src': [CSP.SELF, 'https:', 'data:'],
}
```

## Security Checklist

| | কী করতে হবে |
|---|---|
| `DEBUG = False` production এ | অবশ্যই |
| `SECRET_KEY` env এ, git এ না | অবশ্যই |
| `ALLOWED_HOSTS` specific domains | অবশ্যই |
| HTTPS + SSL redirect | অবশ্যই |
| সব POST form এ `{% csrf_token %}` | অবশ্যই |
| User input `{{ var }}` — auto-escape | Django default |
| ORM use, raw SQL avoid | অবশ্যই |
| File extension validate | অবশ্যই |
| Admin URL rename | Strongly recommended |
| Rate limiting (login/register) | Recommended |
| `python manage.py check --deploy` | Deploy এর আগে |

## Rate Limiting

```python
# pip install ratelimit
from ratelimit.decorators import ratelimit

@ratelimit(key='ip', rate='5/m', method='POST', block=True)
def login_view(request): ...

@ratelimit(key='ip', rate='3/m', method='POST', block=True)
def register(request): ...

@ratelimit(key='user', rate='100/h', block=True)
def api_endpoint(request): ...
```
