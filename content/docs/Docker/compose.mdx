## Docker Compose কী?

একটা `compose.yaml` file এ সব services, networks, volumes একসাথে define করো।
একটা command এ সব উঠে আসে।

```bash
docker compose up -d    # সব services চালু
docker compose down     # সব বন্ধ ও clean
```

---

## File Structure

```yaml
services:        # containers define করো
  web:
    ...
  db:
    ...

volumes:         # persistent storage
  pgdata:

networks:        # custom networks (optional)
  mynet:
```

## ✅ Common Attributes — এগুলো দিয়েই ৯০%+ project চলে

| Attribute | উদাহরণ | কী করে? | কখন লাগে? |
|---|---|---|---|
| `image` | `image: postgres:16` | Docker Hub থেকে রেডিমেড image নেয় | Database, Redis, Nginx এর মতো pre-built image লাগলে |
| `build` | `build: .` / `build: ./backend` | নিজের Dockerfile থেকে image build করে | নিজের code/app থেকে custom image বানালে |
| `ports` | `- "8000:8000"` / `- "80:80"` | Host → Container port map করে | Web app, API বাইরে থেকে access করতে চাইলে |
| `environment` | `- DEBUG=1` / `- DB_HOST=db` | Container এর ভেতরে env variable সেট করে | ছোট-মাঝারি config, dev/test এ সহজ |
| `env_file` | `env_file: .env` | আলাদা `.env` file থেকে variables load করে | `SECRET_KEY`, API keys, DB creds লুকিয়ে রাখতে / git এ না পাঠাতে |
| `volumes` | `- .:/app` / `- pgdata:/var/lib/postgresql/data` | Host folder বা named volume container এ mount করে | Code live reload (dev), persistent data (uploads, db) |
| `depends_on` | `depends_on: [db]` / `condition: service_healthy` | এই service চালানোর আগে অন্য service চালু হতে হবে | Web app db/redis এর উপর নির্ভর করলে |
| `healthcheck` | `test: ["CMD", "pg_isready", "-U", "admin"]` | Container healthy কিনা check করে | DB/service ready না হওয়া পর্যন্ত অপেক্ষা করতে |
| `restart` | `unless-stopped` / `always` / `on-failure` | Container crash/stop হলে auto restart করে | Production এ app সবসময় চালু রাখতে |
| `command` | `python manage.py runserver 0.0.0.0:8000` | Image এর default command override করে | runserver / gunicorn / celery worker চালাতে |
| `container_name` | `container_name: my-django-web` | Container এর নাম fix করে | সহজে identify করতে (scale করলে ব্যবহার করা যায় না) |
| `networks` | `networks: - backend` | Custom network এ join করে | frontend-backend আলাদা network এ রাখতে / security |

<Callout type="info" title="এই ১২টা attributes দিয়েই শুরু করো">
  উপরের attributes গুলো দিয়ে ৯০%+ সাধারণ project চালানো যায়। বাকিগুলো লাগলে নিচের advanced table দেখো।
</Callout>

## ⚙️ Advanced Attributes — দরকার হলে কাজে আসে

| Attribute | উদাহরণ | কী করে? | কখন লাগে? |
|---|---|---|---|
| `profiles` | `profiles: [dev, debug]` | Service কে নির্দিষ্ট profile এ রাখে, `--profile dev` দিলে চালু হয় | dev/debug tool (adminer), staging/prod আলাদা করতে |
| `deploy` | `replicas: 3` / `memory: 512M` | Swarm mode এ scaling, resource limits সেট করে | Production Swarm cluster এ scaling, CPU/Memory limit দিতে |
| `configs` | `source: app-config` / `target: /etc/app/config.yml` | Config file container এ mount করে | Production এ config file securely inject করতে |
| `secrets` | `source: db-pass` / `target: /run/secrets/db_pass` | Sensitive data secure ভাবে container এ দেয় | Production এ DB creds/API keys লুকাতে — `env_file` এর চেয়ে secure |
| `user` | `user: "1000:1000"` | Container root ছাড়া নির্দিষ্ট user এ চালায় | Security: root privilege এড়াতে (production best practice) |
| `entrypoint` | `entrypoint: ["/app/entrypoint.sh"]` | Image এর default entrypoint override করে | Custom startup script (wait for DB, migrate) চালাতে |
| `labels` | `com.example.description: "My web app"` | Container এ metadata/labels যোগ করে | Prometheus, Traefik, logging tools এ auto-discovery |
| `logging` | `driver: json-file` / `max-size: "10m"` | Logging driver ও options সেট করে | Production এ logs rotate/limit করতে, ELK/Syslog এ পাঠাতে |
| `extra_hosts` | `- "myhost:192.168.1.100"` | Container এর `/etc/hosts` এ extra entries যোগ করে | Legacy apps এ hostname resolve করতে (DNS না থাকলে) |
| `shm_size` | `shm_size: 2gb` | `/dev/shm` (shared memory) size বাড়ায় | ML models, বড় PostgreSQL/Redis এ shared memory লাগলে |
| `ulimits` | `nofile: 65535` | Process limits (open files ইত্যাদি) সেট করে | High-traffic app এ file descriptor limit বাড়াতে |
| `sysctls` | `net.core.somaxconn: 4096` | Kernel parameters সেট করে | Network tuning (high connections) করতে |
| `extends` | `file: common.yml` / `service: base-web` | অন্য compose file থেকে service inherit করে | Common configs (restart policy, logging) share করতে |
| `include` | `include: ../monitoring/compose.yml` | অন্য compose file include করে | Modular setup (base + monitoring + caching আলাদা file) |

## Code উদাহরণ

<Tabs items={['image / build', 'ports', 'environment', 'volumes', 'depends_on', 'healthcheck']}>
  <Tab value="image / build">
    ```yaml
    services:
      # Option 1: Ready-made image use করো
      db:
        image: postgres:16

      # Option 2: নিজের Dockerfile থেকে build করো
      web:
        build: .          # current directory তে Dockerfile আছে

      # Option 3: Custom context এবং Dockerfile
      api:
        build:
          context: ./api
          dockerfile: Dockerfile.prod
    ```
  </Tab>
  <Tab value="ports">
    ```yaml
    services:
      web:
        ports:
          - "8000:8000"    # host:container
          - "8080:80"      # host এর 8080 → container এর 80
    ```
    <Callout type="info">
      Format: `"HOST_PORT:CONTAINER_PORT"`
    </Callout>
  </Tab>
  <Tab value="environment">
    ```yaml
    services:
      db:
        image: postgres
        environment:
          POSTGRES_DB: mydb
          POSTGRES_USER: admin
          POSTGRES_PASSWORD: secret

      web:
        # .env file থেকে নাও
        env_file:
          - .env
    ```
    `.env` file:
    ```
    SECRET_KEY=mysecretkey123
    DEBUG=True
    DATABASE_URL=postgresql://admin:secret@db:5432/mydb
    ```
  </Tab>
  <Tab value="volumes">
    ```yaml
    services:
      db:
        image: postgres
        volumes:
          - pgdata:/var/lib/postgresql/data   # Named volume (persistent)

      web:
        volumes:
          - .:/app          # Bind mount — local code → live reload

    volumes:
      pgdata:
    ```
    <Callout type="info" title="Named Volume vs Bind Mount">
      **Named volume** → Docker manage করে, production এ ব্যবহার করো।
      **Bind mount** (`.:/app`) → Local folder directly mount, development এ ব্যবহার করো।
    </Callout>
  </Tab>
  <Tab value="depends_on">
    ```yaml
    services:
      web:
        build: .
        depends_on:
          db:
            condition: service_healthy   # db healthy না হওয়া পর্যন্ত wait

      db:
        image: postgres
        healthcheck:
          test: ["CMD-SHELL", "pg_isready -U postgres"]
          interval: 5s
          timeout: 5s
          retries: 5
    ```
    <Callout type="warn" title="depends_on এর limitation">
      `depends_on` শুধু নিশ্চিত করে db **start** হয়েছে। `service_healthy` use করলে db **ready** হওয়া পর্যন্ত wait করবে।
    </Callout>
  </Tab>
  <Tab value="healthcheck">
    ```yaml
    services:
      web:
        image: nginx
        healthcheck:
          test: ["CMD", "curl", "-f", "http://localhost"]
          interval: 30s      # কতক্ষণ পরপর check
          timeout: 10s       # কতক্ষণ wait করবে
          retries: 3         # কতবার try করবে
          start_period: 40s  # start এ কতক্ষণ grace period
    ```
  </Tab>
</Tabs>

## Complete উদাহরণ

```yaml
services:
  web:
    build: .
    container_name: my-web
    ports:
      - "8000:8000"
    environment:
      - DEBUG=True
      - DATABASE_URL=postgresql://admin:secret@db:5432/mydb
    volumes:
      - .:/app
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped
    networks:
      - appnet

  db:
    image: postgres:16
    container_name: my-db
    environment:
      POSTGRES_DB: mydb
      POSTGRES_USER: admin
      POSTGRES_PASSWORD: secret
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U admin -d mydb"]
      interval: 5s
      timeout: 5s
      retries: 5
    networks:
      - appnet

volumes:
  pgdata:

networks:
  appnet:
```

## Commands

```bash
# সব services চালাও (background)
docker compose up -d

# Build করে চালাও
docker compose up -d --build

# Logs দেখো
docker compose logs -f
docker compose logs -f web    # শুধু web service

# Status দেখো
docker compose ps

# সব বন্ধ করো (volumes রেখে)
docker compose down

# সব বন্ধ করো + volumes মুছো
docker compose down -v

# একটা service restart করো
docker compose restart web

# Container এ ঢোকো
docker compose exec web bash
```
