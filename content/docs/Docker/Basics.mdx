## Docker কী?

Docker হলো একটা platform যেটা দিয়ে তুমি তোমার application কে একটা **isolated environment** এ package করে যেকোনো machine এ run করাতে পারো।

> "আমার machine এ কাজ করছে কিন্তু তোমার machine এ করছে না" — এই সমস্যার সমাধান হলো Docker।

## Image vs Container

| | Image | Container |
|---|---|---|
| কী? | Blueprint | Running instance |
| Editable? | ❌ Read-only | ✅ Writable layer আছে |
| একটা থেকে কতটা? | অনেক container | একটাই image |

<Callout type="info" title="সহজ উদাহরণ">
  Image হলো **রেসিপি**, Container হলো **রান্না করা খাবার।** একটা রেসিপি থেকে অনেকগুলো খাবার বানানো যায়।
</Callout>

## প্রথম Command

```bash
# Ubuntu image pull করে run করো
docker run ubuntu

# কী হলো?
# 1. Local এ ubuntu image আছে কিনা check করলো
# 2. না থাকলে Docker Hub থেকে pull করলো
# 3. Image থেকে container তৈরি করলো
# 4. Run করলো, তারপর বন্ধ হয়ে গেলো
```

<Callout type="warn" title="কেন বন্ধ হয়ে গেলো?">
  Container ততক্ষণ চলে যতক্ষণ তার **main process** চলে। Ubuntu এর কোনো main process না থাকায় সাথে সাথে বন্ধ হয়ে যায়।
</Callout>
